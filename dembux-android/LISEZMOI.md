# Dembux pour Android

App vocale pour parler à Dembux (serveur quinte-flux sur Railway).

- Gros bouton micro : tu parles, Dembux répond à voix haute.
- Tu peux aussi écrire.
- Bouton « Dembux » dans les réglages rapides (volet du haut) : lance l'écoute directement, même écran verrouillé.
- Le code d'accès se tape dans l'app au premier lancement : aucun code ni clé n'est dans ce dépôt.

L'APK est compilé automatiquement par GitHub (onglet Actions) à chaque modification,
et publié dans les Releases du dépôt (fichier `Dembux.apk`).
